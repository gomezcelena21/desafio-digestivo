# 🧠 Desafío Digestivo

¡Bienvenido al Desafío Digestivo! 🎮🍎

Un juego educativo pensado para aprender sobre el sistema digestivo mientras respondés preguntas, superás desafíos y descubrís qué ocurre con los alimentos dentro de nuestro cuerpo.

## 🎯 ¿Qué vas a aprender?

- 👄 Qué ocurre en la boca
- 🌀 Cómo funciona el esófago
- 🥣 Qué hace el estómago
- 🔬 Cómo trabaja el intestino delgado
- 💧 Qué función cumple el intestino grueso
- 🚪 Qué ocurre al final del recorrido digestivo

## 🏆 ¿Cómo se juega?

Respondé las preguntas y avanzá por el recorrido del sistema digestivo.

⭐ Sumá puntos  
❤️ Cuidá tus vidas  
🔥 Conseguí rachas de respuestas correctas  
🧠 Aprendé con las explicaciones después de cada pregunta  
🏅 ¡Intentá conseguir la mejor medalla!

Si una respuesta no es correcta, tendrás una nueva oportunidad de repasar el tema con una pregunta diferente.

## 🌟 Objetivo

Aprender de manera divertida cómo funciona nuestro sistema digestivo.

¡Prepará tus conocimientos y comenzá el desafío! 🚀
